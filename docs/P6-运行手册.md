# P6 运行手册

当前实盘方案：**激进版（-50%）**（2026-11-06 起；美股 2 倍纳指 QLD 80% 不带均线 + A股 中证1000 80% 带均线），配置在 `quant/live/plan.py`。之前 2026-11-04 至 11-05 是激进版（QQQ 90%，上限 -30%）。

系统只出数字和提醒，不自动下真实订单。模拟盘只允许 moomoo 的 SIMULATE 环境，代码里写死。

## 每天（工作日悉尼时间 09:00，自动或手动）

```bash
cd <仓库目录> && ./scripts/daily.sh
```

- 记一行合并人民币份额净值到 `live/nav.csv`，写 `live/daily-<日期>.md`。
- 合并回撤 ≤ -15%：Mac 弹通知“复盘提醒”，停下来复盘，**不自动交易**（你 2026-10-31 的决定）。
- 合并回撤 ≤ -50%：弹通知“触及上限”，这是你设的实盘上限（2026-11-06 从 -30% 改为 -50%；2026-11-04 从 -20% 改为 -30%）。
- 最旧价格超过 5 天（比如数据源没更新）时当天不记账，日志里会写“价格可能过期”。
- 同时标记影子盘市值；每月第一个工作日影子盘按新信号自动调仓（纸面，不涉及真实账户）。
- 日志：`live/logs/daily.log`。

## 每月（1 日 09:30，自动或手动）

```bash
cd <仓库目录> && ./scripts/monthly.sh
```

- 本月调仓单：`live/orders/<YYYY-MM>/调仓单.md`（每个账户另有 CSV），同时存一份持仓快照，用来判断你有没有照单执行。
- 上月偏差报告：`reports/P6-偏差-<YYYY-MM>.md`。
- 调仓单规则：新投入的钱先补低配；只有高出目标超过 5 个百分点或目标为 0 的资产才卖。

## 你要维护的两个文件

1. `config/holdings.csv`：每次真实交易后更新股数和现金（同一标的多批买入可以分多行，填上 `cost_basis`、`buy_date` 方便税务）。
2. `config/flows.csv`：入金填正数、出金填负数，例如 `2026-11-15,moomoo,2000,USD,工资`。不记的话入金会被当成收益，回撤会算错。晚录、补录过去日期都可以：下一次记账会把还没入账的现金流补进来。入金后请同时更新 `holdings.csv` 的现金。

## moomoo 模拟盘（需要你自己登录）

1. 从 moomoo 官网下载 OpenD（Mac 版），打开后用你的 moomoo 账号登录。密码只在 OpenD 里输入，系统不读不存。
2. 连通测试（查资金、持仓，下 1 股远低于市价的 SPY 限价单再撤掉，全部在模拟盘）：

   ```bash
   cd <仓库目录> && .venv/bin/python -m quant.live.moomoo_paper --check
   ```

3. 每月影子盘调仓后，让模拟盘持仓跟上影子盘（按差额下限价单，限价 = 参考价 ±0.5%；卖出不超过已有持仓，不会做空；同月重复运行会被拒绝）：

   ```bash
   cd <仓库目录> && .venv/bin/python -m quant.live.moomoo_paper --sync 2026-11
   ```

   订单记录在 `live/paper/<YYYY-MM>.csv`，下月偏差报告会取回成交并计算成交价差和未成交。

## 自动运行（可选，需要你同意）

```bash
cd <仓库目录> && ./scripts/install_schedule.sh
```

装到 `~/Library/LaunchAgents`；卸载加 `--uninstall`。装好后立刻实测一次：`launchctl kickstart -k gui/$(id -u)/com.quant.daily`，再看 `~/Library/Logs/quant-daily.log`（launchd 层面的报错写在这里，脚本自己的输出仍在 `live/logs/`）。Mac 睡眠时错过的任务会在唤醒后补跑。仓库不要放在“文稿”里（macOS 不允许后台任务访问“文稿”）。

## P6 验收

影子盘和模拟盘记满 3 个月（激进版（-50%）从 2026-11-06 重新起算，约 2027-02 初）后，看连续三份偏差报告：偏差的每一项都能对上原因（整手、现金、分红、成本、成交价差、未成交、没照做），才算“偏差可以解释”，再由你决定是否进入 P7。

> 声明：本系统输出不是投资建议；回测和模拟成交都不代表未来收益。
