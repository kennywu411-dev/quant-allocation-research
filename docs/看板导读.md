# 看板导读

> 研究记录，不是投资建议；作者不是持牌金融顾问；历史回测不代表未来收益。

看板网址：<https://kennywu411-dev.github.io/quant-allocation-research/dashboard/>。页面由 `quant/alpha/dashboard.py` 生成，数字全部读自 `research/` 下的结果文件；图表库 ECharts 5.6.0（Apache-2.0）随页面一起托管，不请求外部网络。页面上没有实时行情，标注的“数据截至”“页面生成”是文件里的真实日期。

页面只有一套内容，不分读者版本：首屏是一句结论和一张筛选图；每张图上方有一句“这张图在说什么”；术语在第一次用到它的图下面就地解释一句。

## 从上到下

| 位置 | 是什么 | 为什么这样放 |
|---|---|---|
| 首屏：标题和筛选图 | 每个点是一次试验：19 种先登记后检验，8 种过了及格线，按各自的把握排在 0 到 1 的横线上，没有一种到 0.95 | 不用术语就能看懂结论，每个点都能点开核对 |
| 筛选图下面的两段话 | “没找到能用的办法，这份研究有什么用”和准确口径 | 先回答外行的问题，再给内行准确说法 |
| 01 至 03 | 19 次试验清单、t 值与通缩夏普的及格线图、选中试验的成绩单；点一行，其余图表跟着切换 | 只看 t 值会高估把握 |
| 04 和完整数字表 | 每个因子每个月排对还是排反；19 次试验的全部数字，可排序 | 失败的试验同样列出 |
| 05 | 组合与基准的净值、最深一次下跌（阴影）、组合除以基准（虚线）、水下回撤；拖时间条按区间重算 | 看相对基准多了多少、要忍多深的下跌 |
| 06、07 | 每个月、每一年比基准多赚或少赚多少 | 看优势集中在哪些年份 |
| 08 至 11 | 单个因子：五分组收益、逐月 RankIC、扣成本前后的超额与换手 | 排得准不等于扣成本后能赚钱 |
| 12 | 勘误：修正前后的四个数字并排 | 修正让结果变好，更要原样公开 |
| 13 至 15 | 8 类数据的覆盖时间和行数、每个月的股票池数量 | 先交代数据，再谈结果 |
| 六个环节 | 流程、对应的代码文件和读数 | 说明这是一套流程 |
| ETF 配置线 | 加均线的配置方案和两个基准的年化、最差回撤、坏年份表现 | 同一仓库的另一条线，收益和代价都列出 |

## 两个容易误读的地方

- 净值图上方的“年化收益差”是组合年化减基准年化，方便按时间段重算；试验登记用的是把每个月的超额连乘起来再折成年化。判定只用登记口径。
- 04 号图的逐月 RankIC 来自月度流水线（Tushare 日线合成的周线），两轮登记试验用的是 baostock 周线缓存，数字有小的出入。

## 版式参考

只借鉴思路，没有使用这些项目的代码：QuantStats、pyfolio（净值、水下回撤、月度热力图、年度柱；最深回撤标在曲线上）、Alphalens（因子按收益、排序能力、换手三段）、Qlib（扣成本前后成对、超额单独一条线）、TradingView lightweight-charts（十字光标与时间轴缩放的交互约定）、Grafana（门槛画成线、每个面板带一句说明）、英国国家统计局与 Datawrapper 的图表文字规范（标题先说结论、术语用日常说法）。
