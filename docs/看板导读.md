# 看板导读

> 研究记录，不是投资建议；作者不是持牌金融顾问；历史回测不代表未来收益。

看板网址：<https://kennywu411-dev.github.io/quant-allocation-research/dashboard/>。页面由 `quant/alpha/dashboard.py` 生成，数字全部读自 `research/` 下的结果文件；图表库 ECharts 随页面一起托管，不请求外部网络。页面上没有实时行情，标注的“数据截至”“页面生成”是文件里的真实日期。

## 四个词

- **RankIC**：每个月把股票按因子值排名，再按下个月收益排名，两个排名的相关系数。正数说明排对了。
- **t 值**：结果离“纯属运气”有多远，一般 3 以上才算显著。
- **通缩夏普（DSR）**：试得越多，越容易碰上一个好看的结果。通缩夏普把试验次数算进去，给出“这不是运气”的把握程度，0 到 1 之间，本项目的门槛是 0.95。
- **超额**：组合收益减去同一股票池等权持有的收益。

| 顶栏和状态格 | 试验数、过登记门槛数、撑过折扣数、通缩夏普最高值、股票数、本地缓存行数、测试通过数 | 结论放在第一屏 |
| 01 试验清单 | 19 次试验逐行列出，可筛选、可排序；点一行，其余图表跟着切换 | 失败的试验同样列出 |
| 02 门槛图 | 横轴 t 值，纵轴通缩夏普，虚线是门槛；右上角是通过区 | 只看 t 值会高估把握 |
| 03 单项读数 | 选中试验的各项指标和离门槛的差距 | 可以逐个核对 |
| 04 因子 × 月份 | 每个因子每个月的 RankIC，蓝色排对、橙色排反 | 因子不是每个月都灵 |
| 05 净值与水下回撤 | 两个观察组合和基准，起点为 1；拖时间条，上方读数按区间重算 | 看相对基准多了多少、最深跌多少 |
| 06、07 月度与分年超额 | 每个月、每一年比基准多赚或少赚多少 | 看超额集中在哪些年份 |

| 12 勘误 | 修正前后的四个数字并排 | 修正让结果变好，更要原样公开 |

| ETF 配置线 | 加均线的配置方案和两个基准的年化、最差回撤、坏年份表现 | 同一仓库的另一条线，收益和代价都列出 |

## 两个容易误读的地方

- 净值图上方的“年化收益差”是组合年化减基准年化，方便按时间段重算；试验登记用的是月度超额的均值年化。判定只用登记口径。
- 04 号图的逐月 RankIC 来自月度流水线（Tushare 日线合成的周线），两轮登记试验用的是 baostock 周线缓存，数字有小的出入。
